# Weldone 工艺规划

Weldone 在浏览器中导入 STEP 模型、提取焊道、匹配焊接模板及工艺参数，并保存规划任务。五个工作区分别为工艺规划、焊接模板库、工艺参数库、设备控制和生产统计。

## 本地运行

安装 Node.js 22 或更新版本和 pnpm，然后运行：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

打开 [本机预览](http://127.0.0.1:5236/)。Windows 上也可以双击 `启动平台.cmd`。工作区保存在当前浏览器的 IndexedDB 中。使用工艺规划工具栏中的「导出任务」和「导入 PF 文件」转移规划任务。导入 STEP 或切换模型后，点击「一键规划」开始提取。

## 规划、碰撞和回放

一键规划按删除、合并、打断的顺序预处理焊缝，随后匹配模板或工艺参数并生成路径。生成路径的每道都使用南洋机头 STL 和当前工件网格检查干涉。检测使用当前相机盖位置，相机视野体积排除在碰撞几何之外。焊丝末端 1 mm 的接触区域从网格中裁除。距离低于 0.25 mm 时报告间隙不足。一键规划期间，按钮显示碰撞检测百分比。日志记录检测与复检耗时，以及含裁剪的总耗时。

检测到包角碰撞时，U 形拆为两条 L 形并复检，L 形在连接点断开并复检。默认裁去普通焊段中已确认碰撞的区间。在「工艺规划设置 → 路径设置 → 碰撞检测」关闭「碰撞检测打断焊缝」后，普通焊段仍检查并保留碰撞记录。

在结构树选中某一道，右侧「焊接规划」可按工艺焊速播放机头，也可按里程查看采样点和碰撞区间。回放和检测使用同一机头位姿，包括层道和点位偏移。此检测覆盖机头与工件之间的几何干涉。

## 开发验证

```powershell
node --test tests/*.test.mjs
pnpm build
```

规划入口为 `src/App.jsx`，位姿计算为 `src/weldToolPose.mjs` 和 `src/weldLayerLayout.mjs`，碰撞计算为 `src/weldCollision.mjs`。本地 STEP 提取接口由 `scripts/local-step-extraction.mjs` 提供。构建生成 `dist/client/`，同时准备 Sites 的 Worker 和托管清单。
