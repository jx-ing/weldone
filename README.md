# 原版工艺规划平台

参照本机 `C:\Users\a\AppData\Local\Programs\Weldone` 安装版 1.0.4 实现的独立本地平台。主要复刻工艺规划页面的黑色标题栏、横向导航、橙色主题、三栏工作区、模型工具与日志区域。代码独立放在本项目中，草稿使用独立的浏览器存储键，未修改现有工作台与正式平台。

## 使用

本机预览地址：http://localhost:5236/ 。双击 `启动平台.cmd` 可以启动并打开页面。启动器识别已运行的本平台；其他服务占用 5236 时会停止启动并说明原因，不会终止其他进程。关闭启动终端会停止由该终端启动的服务。

首次进入“工艺规划”加载 `111.step` 的实际几何，共 33 个零件，不自动生成焊道。点击“人工点选焊道”，选择模型边线或在模型表面依次取点，确认属性后点击“生成焊道”。可以拖动旋转、滚轮缩放；点击视角立方体或下方按钮切换视角。

可编辑焊缝名称、焊脚、接头类型、焊接位置、方向、起弧延时及工艺参数。选择“保存草稿”保存在当前浏览器本机存储中，刷新会恢复；更改未保存时显示“有未保存修改”。不同主机名、端口和浏览器的存储彼此独立，请保持使用 `localhost:5236`。

“一键规划”基于当前启用的人工焊道建立路径预览。在“路径仿真”可播放、暂停、拖动进度和改变速度。“焊接模板库”支持整道/局部分类、搜索、新建、编辑、复制、删除和条件匹配后应用到当前焊道。导出、导入使用本平台 JSON 草稿，支持往返恢复。

## 已实现页面

- 工艺规划：结构树、零件列表、焊缝筛选、启用开关、属性与工艺参数、三维联动、日志筛选。
- 路径仿真：选中焊缝的示例播放、进度、倍速、视图设置。
- 生产执行：初始化、终止和执行预览；全部仅作用于示例。
- 设备控制：切换设备详情，真实显示未连接。
- 焊接模板库：本地示例模板与用户创建的模板。
- 产能统计：根据当前草稿计算工件数、焊缝数、长度、已规划数量；不是生产统计。
- 调试工具、系统管理：本地诊断、项目信息、草稿保存和备份。

## 范围

这是可运行的前端交互原型。示例 STEP 已在本地转换为真实三维几何；浏览器未提供任意 STEP / SPF / IFC 导入。暂不自动识别焊道，没有机器人运动学、碰撞避障、相机定位、设备通信或真实生产控制。原版的 PF 与任务导出入口在本原型中对应明确标注的 JSON 草稿操作。几何为轻量示例，不会因焊脚或接头编辑重新生成 CAD。路径播放不表示生产校验通过。

复用安装版图标、空状态图形和工作角示意图；场景与视角立方体由 Three.js 实时渲染。全局字体使用系统字体，标准控件图标使用 Lucide，原版菜单与个别工具图标尚有细节差异。未公开发布。

## 焊接模板（2026-10-28）

本项目在交流和界面中统一称为“原版工艺规划平台”，地址为 http://localhost:5236/。

- 整道模板：从模型中选择具有完整起点和终点的焊道新建；匹配焊脚（0.5 mm 步长）、转角数量及各转角的标准角度和角度容差、段数量、各段焊接位置/接头/几何顺序、坡口和两端过焊孔。精确模式额外逐段匹配长度，每段默认容差 ±10 mm，可分别调整。

- 新建固定模板使用与局部模板相同的编辑流程，包含匹配条件、多层多道、控制点和工艺设置。固定模板在模板库独立分类中显示，可搜索、新建、编辑、复制、删除或复用为局部模板。复用带入定位所需的焊缝形状、段长度、转角和独立点位位置（含层高和道偏移），焊脚、焊接位置、接头等业务条件与工艺独立设置。
- 模板保存和删除即时保存至本机；整道复制先选择来源并编辑后保存，局部复制直接保存；固定模板同样持久化。规划草稿导出/导入包含模板及固定骨架，兼容旧版模板。应用产生独立且沿焊接方向排序的点位副本，模板后续修改不影响副本。
- 当前模型仍为轻量示例。连接点邻域、段序列、转角和完整端点由焊道数据提供，尚未接入真实 CAD 自动识别。没有完整端点证据的焊道不会自动通过整道匹配。

## 控制点拖拽与偏移联动（2026-10-28）

“控制点与工艺”采用左侧示意图、右侧参数的并排布局。控制点可直接拖动，默认按初始拖动方向锁定为沿焊道或垂直焊道；也可以选择约束按钮或拖动对应方向手柄。位置偏移采用局部坐标：X 沿当前焊缝段方向，Y 为面内垂直方向，Z 为高度。XY 视图显示 X/Y 偏移，XZ 视图显示 X/Z 偏移，XY 中也会标注非零高度。修改数值会即时更新点位，拖拽会回写数值；虚线连接基础点位和偏移后点位。箭头键每次微调 1 mm，Shift + 箭头键微调 10 mm。

固定模板与局部模板一样使用 XYZ 偏移及示意图拖拽编辑点位；这些相对基准点的位置可保存和复用。匹配与工艺内容保存供再次编辑，复用时仅带入位置。图中转角按设置的标准夹角绘制，不代表真实 CAD 几何。

本次新增交互已在浏览器实测：沿向拖拽只修改 X，面内法向拖拽只修改 Y，高度视图拖拽只修改 Z，数值编辑与图形双向同步；固定骨架拖拽同步点位位置，无控制台报错。验收截图：`artifacts/template-point-drag-verified.png`（临时验收草稿，未修改已有模板）。回归命令：`node --test tests/template-preview.test.mjs tests/templates.test.mjs tests/sites-worker.test.mjs`。

## 逐转角标准角度与角度容差（2026-10-28）

整道和局部模板的转角条件均改为每个转角一组标准角度与角度容差，按焊道顺序对应连接点。例如第一个转角可设为 60° ±3°，第二个设为 120° ±8°。每增加一个转角自动增加一组，新增默认 90° ±5°，已保留项不变；减少转角或焊缝段数量时同步移除超出的组。每个实测夹角须满足对应标准值 ± 容差，边界包含，合法转角范围为 0–360°。

点位示意图的 XY 平面按各个标准夹角实时绘制焊缝段和角度弧线，标注转角序号及角度；90° 是直角，180° 是平直。也可直接在示意图上方修改各组参数，和匹配条件同步。容差只影响匹配范围，不改变图形。XZ 为高度展开视图，夹角请在 XY 查看。点位拖拽使用更新后的局部焊道方向。

旧版共享角度范围 [最小角度, 最大角度] 自动转为每组的中点标准角度及半区间容差，保留原先匹配范围。固定模板仍仅复用点位骨架，角度匹配条件来自新建模板自身。

验证：浏览器中实测从两组参数绘制的夹角为 75° 与 120°；修改标准角度会改变图形，修改容差不改变图形；增减转角后参数组数量正确。截图见 `artifacts/template-standard-angles-verified.png`，验收草稿未保存，原有模板数据未更改。自动回归命令：`node --test tests/template-corners.test.mjs tests/template-preview.test.mjs tests/templates.test.mjs tests/sites-worker.test.mjs`。

## 匹配条件示意图与整道转角（2026-10-29）

## 开放闭合、基准点与多层多道（2026-10-29）

整道、局部模板都具有“焊道形式”：开放允许直线、曲线；闭合另允许圆弧。示意图使用真实曲线路径、圆弧和闭合轮廓，点位沿实际弧长定位。手工模板的曲线用“弯曲程度、左/右侧”调整，单段闭合曲线用宽高调整，圆形用半径调整，多段圆弧可调半径和角度。多段闭合的最后一段自动连接起点，其长度和圆弧半径由轮廓推导。旧版手工整道闭合模板最后一个转角的标准角度、容差可手动设置，修改几何不会覆盖输入值；若标准角度与几何收尾夹角不同，图中虚线标出标准角方向，实线保持闭合轮廓。局部闭合模板的收尾转角继续由轮廓推导。手工模板的转角设置支持逐项新增、删除。新建整道模板按下面的来源焊道流程生成，标准角度和几何取自模型。

每道初始包含起点、终点及各段连接点；增减焊缝段会同步所有道的自动基准点。人工点必须选择其中一个基准点，X 沿焊道、Y 为平面内垂直、Z 为高度，均相对所选点计算。基准点自身偏移也会带动引用它的人工点。删除段导致引用失效时，需重新选择后才能保存。固定模板保存、复用点位及其基准关系和位置，仍不包含工艺参数。

“多层多道与控制点”支持新增、删除层和道，至少保留一层一道；每道独立保存控制点、姿态、跟踪及工艺覆盖。新增层/道会复制当前道作为初值，后续互不影响。层高 Z、道横移 Y、道附加高度 Z 均以 mm 设置并显示在点位图中。几何与匹配条件为模板共享；应用和草稿导入/导出保留所有层道，应用后的属性面板可逐道查看。

## 整道模板的来源焊道与逐段长度容差（2026-10-29）

## 工艺参数库（2026-10-29）

主导航新增“工艺参数库”，支持新建、编辑、复制、删除和名称/接头/坡口搜索，可按焊机参数类型筛选。适用条件包含接头类型、坡口类型/角度/深度；应用到焊道前逐段检查接头及坡口匹配。

参数按适用条件、起弧/焊接/收弧、弧坑回填、偏移/姿态/摆动分组。支持各阶段电流、电压或修正值、起收弧时间和各阶段JOB号，以及焊接速度、Y/Z偏移、推拉角、俯仰角。主焊摆动和回填摆动独立设置幅度、频率、左右停留。回填还包含启用状态、距离、速度及**实际焊接速度（人工填写）**。速度单位mm/min，距离/偏移/幅度单位mm，时间单位s，频率Hz；电压修正值使用焊机自身数值标度。

分别模式使用电流、电压；一元模式使用电流、电压修正值；JOB模式禁用焊接模式、电流、电压、修正值，起弧/焊接/收弧/回填分别引用各自JOB号。未生效字段可保留供再次切换模式编辑，但不进入已应用的有效参数快照。点位工艺覆盖的显示同样遵循当前模式。新工艺的电流、电压、速度、JOB等需人工填写，未提供任意焊接配方。

在模型中选择焊道后可从工艺库应用，或在右侧“工艺参数”中选择工艺方案。应用后保存草稿，刷新和导出/导入均可保留；已应用快照独立于原库条目。旧草稿兼容空工艺库。当前离线平台保存JOB引用，未接入焊机程序读取与执行。

同时简化整道/局部/固定模板的控制点交互图：移除重复的转角输入条与底部拖动提示/XYZ摘要；匹配条件中的转角编辑、图中角度标注和右侧点位参数保留。

验证新增 tests/process-parameters.test.mjs，覆盖三种模式、未生效字段排除、人工实际速度、回填摆动、匹配、应用快照、复制编辑删除与草稿往返。

## 页面内编辑与工艺焊脚条件（2026-10-29）

工艺参数、整道/局部/固定焊接模板的新建保持弹窗，列表保留在弹窗后方；整道来源选择、局部中新建固定模板及需要填写的复制/复用新建流程同样使用弹窗。编辑已有条目时进入主工作区页面，提供返回列表及底部保存按钮，不使用编辑弹窗；返回时未保存的修改由页内提示处理。固定模板创建关闭后保留原局部草稿。

工艺参数适用条件新增单一焊脚数值（mm、步长0.5、最小0.5），保存/复制/导入导出及应用快照均保留。应用时与焊道焊脚精确匹配。旧记录与快照兼容读取，未提供焊脚的旧工艺显示待补充，需补填才能保存或重新应用，不自动推定尺寸。

## 统一焊缝属性与多层多道工艺（2026-10-29）

右侧仅保留“焊缝属性”，集中显示基本信息、方向、模板方案、工艺方案、已应用控制点和已应用工艺；删除原独立工艺参数页、起弧延时及111.step说明。工艺库的新建仍使用弹窗，已有记录编辑仍使用页面。

工艺库分三部分：适用条件（焊机型号自由填写、实芯/药芯焊丝、1.2/1.4/1.6 mm直径、CO2或80%CO2+20%AR、MIG/MAG、低碳钢）；匹配条件（焊脚、焊接位置、接头、坡口类型/角度/深度）；多层多道工艺。适用条件作为设备/材料工艺信息保存与检索，应用按模型已有的四项匹配条件核对，焊接位置和接头逐段检查。

每层可新增多道，新增时复制当前道再独立修改，支持删除并至少保留一层一道。每道独立设置一元/分别/JOB、直流/脉冲、起弧/焊接/收弧、回填（含人工实际速度和独立摆动）、Y/Z偏移、推拉/俯仰角、主焊摆动。JOB无效字段逐道从有效快照排除，所有层道随应用和JSON草稿往返保留。应用摘要可切换层道；模板点位覆盖按同序层道的工艺模式显示。

旧单道工艺打开后保留原参数为第一层第一道；旧库条目和已应用快照均可读取，缺少的新适用/匹配条件需补填后重新应用，不虚构焊机或材料数据。

## 匹配流程与模板基础工艺（2026-10-29）

一键规划按用户流程图逐条处理启用焊道：①整道模板匹配直接生成预览路径；②未匹配整道时必须先匹配工艺参数；③工艺匹配后，有局部方案则应用到连接邻域，没有局部方案则自动规划；④缺少匹配工艺时保持待处理，禁止启动该焊道预览。规划报告展示各条结果，缺失时可新建整道方案、新建工艺参数、屏蔽或确认删除。新建入口带入当前焊道/来源，屏蔽可通过结构树重新启用。

局部方案检查连续1–3段的连接邻域，不再要求整条焊道只有三段以内；闭合焊道也检查末段到首段的邻域。应用保留实际模型位置、对应原段号及各层道控制点。

整道/局部模板新增“基础工艺”选择框，可挂载工艺参数库方案并展开查看。仅能选择与模板焊脚、焊接位置、接头、坡口相符的方案；保存时再次校验。整道路径携带挂载方案全部层道参数；局部模板把自身基础工艺保存到对应邻域，不覆盖主焊道工艺。JOB无效字段仍按每道排除。模板保存挂载编号，应用时另存独立有效快照；旧未挂载记录保留兼容。基础工艺缺失/不匹配的整道模板不能直接规划；局部挂载不可用则不作为有效局部匹配，按已有有效主工艺自动规划。

新增 tests/weld-matching.test.mjs，覆盖流程全部分支、屏蔽和预览门槛、长焊道/闭合邻域、快照独立、失效绑定及完整基础工艺应用。
