# Weldone 工艺规划

Weldone 在浏览器中导入 STEP 模型、提取焊道、匹配焊接模板及工艺参数，并保存规划任务。顶部菜单依次为工艺规划、生产执行、焊接模板库、工艺参数库、设备控制和生产统计。

## 本地运行

安装 Node.js 22 或更新版本和 pnpm，然后运行：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

打开 [本机预览](http://127.0.0.1:5236/)。Windows 上也可以双击 `启动平台.cmd`。首次启动载入内置 a1a，之后可恢复本机规划草稿。手动导入 STEP 后，点击「一键规划」开始提取。点云支持 TXT、XYZ、PLY 和 PCD。

设备控制的「导入场景文件」支持带 WeldOne 设备标注的内嵌 GLB。导入的工作站和按场景保存的设备修改均在本机浏览器恢复。

生产执行支持虚拟粗定位与精定位点云。模型视图显示粗定位双目的两个三棱锥。「粗定位设置」按当前工件摆放推荐沿激光面法向的起点和终点，两个数值以场景相机为原点，单位为 mm。虚拟相机按需分带扫描以覆盖工件全宽。粗定位按 3 mm 采样，精定位沿仿真寻位轨迹按 0.5 mm 采样。对应的定位视图均可查看点云和下载 PLY。

外部 STEP 提取需要本机 Python 和 OCP。逆向建模另需 NumPy、SciPy 和 Shapely。可以通过 `WELDONE_STEP_PYTHON` 和 `WELDONE_REVERSE_PYTHON` 指定解释器。两个本机接口分别为 `/api/step-extraction` 和 `/api/reverse-model`，作业文件位于系统临时目录。Sites 部署提供静态资源与页面路由，外部 STEP 的几何提取及点云逆向建模由本机服务提供。

## AI 助手

点击顶部「AI 助手」可查看一键规划、任务导出等操作指引。在工艺规划中，勾选「附上本轮规划摘要」即可预览发送内容，其中包括当前选中的焊缝状态和最近三条规划日志。该选项每轮发送后重置。对话在当前页面会话中保留。

助手除了问答，还可以在人工授权下执行本机操作：选中焊缝、启用或屏蔽、修改名称/焊脚/位置/坡口、删除、合并、应用焊接模板或工艺参数、新建焊接模板、一键规划、导出到生产执行、按里程打断、U 形包角改 L 形、撤销、复检和发布生产任务，以及模板/工艺库重命名与删除。模型只会返回操作提案，界面显示任务卡并由你点击「确认执行」后才写入；高风险操作会单独标记。复杂请求可拆成最多 5 步顺序执行，失败会暂停并支持重试剩余步骤；工作区在确认前变化时会刷新预览并要求再次确认。每次操作结果会回填给模型，便于继续追问。

助手也可以打开生产执行、设备控制和生产统计模块，并按模块能力执行选择道次、启动/终止仿真、应用设备修改和导出统计 CSV。工艺类问题会引用本机工艺库记录并声明不含批准状态；缺陷类问题给出通用检查方向，不替代项目批准的工艺与质量规则。

如需让助手引用已批准的受控工艺来源，把 `data/assistant-sources.example.json` 复制为 `data/assistant-sources.json`，按标题、ID、版本、适用范围登记并把 `approved` 置为 `true`。助手只读取并引用已批准条目，回答时会标注来源；未登记时明确说明“没有已批准来源”，不引用其他资料。该文件已被 `.gitignore` 忽略。

验收脚本位于 `qa-harness/assistant-acceptance.mjs`，覆盖 A01–A08，需先启动本地平台，再运行 `node assistant-acceptance.mjs`（可用 `CASE=A04` 单例复跑）。

助手会记录每次成功调用返回的 token 用量（含缓存命中），保存在本机 `data/assistant-usage.json`，并在助手「模型服务设置」里显示累计与今日用量；也可以直接访问 `GET /api/assistant/usage` 查看总量、按天汇总和最近 20 次记录。该统计只覆盖启用后经本平台发出的调用，历史调用无法回溯；API Key 在 DeepSeek 平台的整体用量与账单需在 platform.deepseek.com 查看。

模型服务可以随时更换：点开助手右上角的齿轮，在「服务预设」里选择 DeepSeek、OpenAI、本机模型（Ollama）或自定义兼容服务，填写接口地址、模型名称和 API Key 后保存并测试。配置保存在项目根目录的 `.assistant-config.json`（本机文件，已被 `.gitignore` 忽略），切换后立即生效，无需重启；该文件优先于 `.env.local`，删除它即可回到环境变量配置。

首次配置也可以双击 `设置AI密钥.cmd`：它默认写入 DeepSeek 官方 API，校验密钥后保存到 `.env.local`。未使用应用内设置时，`.env.local` 或进程环境变量中的 `WELDONE_AI_API_KEY`、`WELDONE_AI_BASE_URL`、`WELDONE_AI_MODEL` 同样生效，只填密钥即使用 `https://api.deepseek.com/v1` 和 `deepseek-chat`。地址使用 HTTPS，本机环回地址也支持 HTTP。

在 GitHub Pages 打开「AI 助手 → 模型服务设置」，选择提供商或自定义 OpenAI 兼容接口，填写自己的模型名称和服务所需的 API Key，点击「连接并测试」。浏览器直接访问填写的服务，该服务须允许网页来源的跨域请求。测试只发送一条简短消息。咨询时会发送问题、近期对话和本机焊缝、模板及工艺快照。连接仅在当前标签页内存中生效，刷新页面后需要重新输入。可在设置中主动断开。

本地版和网页版均支持离线操作。例如输入「打开生产统计」「屏蔽 W10001」「W10001 拆成两个 L 形包角」，核对任务卡后点击「确认执行」或「取消」。开放式问答和更复杂的表达使用已连接的模型。每位使用者自行选择服务，发布仓库与网页构建均排除个人密钥及本机使用记录。

## 规划、碰撞和回放

一键规划按删除、合并、打断的顺序预处理焊缝，随后匹配模板或工艺参数并生成路径。工具头碰撞检测默认关闭，可在「工艺规划设置 → 路径设置 → 碰撞检测」启用。启用后，检测使用当前机头及相机盖位置，相机视野体积排除在碰撞几何之外。焊丝末端 1 mm 的接触区域从网格中裁除。距离低于 0.25 mm 时报告间隙不足。按钮和日志分别显示检测进度及用时。

包角发生碰撞时保留包角类型，记录干涉位置。仍有干涉的包角焊缝暂停排入焊接顺序。默认裁去普通焊段中已确认碰撞的区间。在「工艺规划设置 → 路径设置 → 碰撞检测」关闭「碰撞检测打断焊缝」后，普通焊段仍检查并保留碰撞记录。

在结构树选中某一道，右侧「焊接规划」可按工艺焊速播放机头，也可按里程查看采样点和碰撞区间。回放和检测使用同一机头位姿，包括层道和点位偏移。此检测覆盖机头与工件之间的几何干涉。

## 生产执行与设备

「导出任务」把当前规划发布为独立的生产快照。PF 下载在导出菜单内，生产执行也可直接导入 PF。生产页的一键执行仿真当前选中道次，会依次寻位、接近焊缝、焊接和收枪。发布后停用已分配的机械臂，需要重新分配并发布。仿真记录可在统计中查看，起弧产量只使用起弧执行数据。

设备管理支持按精定位相机品牌配置结构光和线激光。场景已有的机器人和相机沿用模型标定。新增结构光可选装到已有机械臂，两个类型在同一机械臂上同时可用时默认定点拍照。场景中缺少模型绑定的附加设备可保存配置，有效的场景机械臂才用于轨迹分配和仿真。

## 开发验证

```powershell
node --test tests/*.test.mjs
pnpm build
```

规划入口为 `src/App.jsx`，位姿计算为 `src/weldToolPose.mjs` 和 `src/weldLayerLayout.mjs`，碰撞计算为 `src/weldCollision.mjs`。本地 STEP 提取接口由 `scripts/local-step-extraction.mjs` 提供。构建生成 `dist/client/`，同时准备 Sites 的 Worker 和托管清单。
